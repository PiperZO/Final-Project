# Title
Supremedoll Falling Items

## Repository
https://github.com/PiperZO/Final-Project

## Description
Players can choose between two characters who walk back and forth across the screen holding baskets to catch falling items unique to the character. This project combines programming, animation, and visual design to create an interactive game.

## Features
- Character Selection
	- Players will be able to choose between two different characters before starting the game.
- Character Movement
	- Characters will walk across the screen while holding a basket. I will use keyboard controls and sprite animations to create movement.
- Custom falling items
	- Each character will have their own unique set of items falling from the sky. I will use different images and sprites for each character.
- Collision Detection
  - I will use Pygame's collision detection to determine when falling items land inside the character's basket.
- Scoring System
  - Players will earn points for every item they successfully catch. The score will be displayed on the screen.
- Increasing Difficulty
  - The falling items will gradually increase in speed as the game progresses to make it more challenging.
- Game Over and Restart
  - Players will have a limited number of missed items before the game ends. A game-over screen will display their final score and allow them to restart.


## Challenges
- Learning how to create walking animations using character sprites.
- Understanding collision detection between falling objects and the character's basket.
- Learning how to organize the code so each character has their own unique falling items.
- Figuring out how to manage multiple falling objects, scoring, and increasing difficulty.

## Outcomes
Ideal Outcome:
- Create a fully playable game with two selectable characters, walking animations, unique falling items for each character, and a scoring system. Ideally, the game will also have a start screen, increasing difficulty, and a game-over screen with a restart option.

Minimal Viable Outcome:
- Create a working game with at least one character who walks across the screen holding a basket and catches falling objects. The game will include basic collision detection, a score counter, and the ability to restart.


## Milestones

- Week 1
  1. Set up Python, Pygame, and the game window.
  2. Create the character holding a basket and program basic left and right movement.

- Week 2
  1. Create falling objects that appear at the top of the screen and move downward.
  2. Give each character their own unique falling items and add walking animations.

- Week N (Final)
  1. Add increasing difficulty, a game-over screen, and a restart option.
  2. Test the game, fix bugs, and improve the graphics and overall gameplay.
